Glossário — IA aplicada ao Mercado Financeiro e à Análise de Dados
Termo	Significado
IA	Inteligência Artificial: tecnologias capazes de executar tarefas que normalmente exigiriam capacidades humanas, como análise e reconhecimento de padrões.
Machine Learning	Técnica de IA que permite aos sistemas aprender padrões a partir de dados.
Big Data	Conjunto de grandes volumes de dados que podem ser analisados para encontrar padrões e informações.
Data Analytics	Processo de analisar dados para obter informações e apoiar decisões.
Business Intelligence (BI)	Conjunto de ferramentas e métodos utilizados para transformar dados em informações úteis para negócios.
Power BI	Plataforma da Microsoft utilizada para conectar, modelar, visualizar e analisar dados.
Open Finance	Sistema que permite o compartilhamento de dados e serviços financeiros, mediante autorização, dentro das regras aplicáveis.
Fraude	Atividade realizada para obter vantagem indevida por meio de engano ou manipulação.
Compliance	Conjunto de práticas destinadas a garantir conformidade com leis, normas e políticas.
Gestão de riscos	Processo de identificar, avaliar e administrar riscos que podem afetar uma organização.
Algoritmo	Conjunto de instruções utilizadas para solucionar problemas ou executar processos.
Modelo preditivo	Modelo utilizado para estimar resultados ou comportamentos futuros a partir de dados.
DAX	Linguagem utilizada no Power BI para criação de cálculos e medidas.
Governança de dados	Práticas e regras utilizadas para garantir qualidade, segurança, organização e utilização adequada dos dados.
Viés algorítmico	Resultado sistematicamente distorcido de um modelo que pode decorrer dos dados, métodos ou processos utilizados.
Dashboard	Painel visual utilizado para apresentar indicadores, informações e resultados de forma organizada.
Dados financeiros	Informações relacionadas a operações, clientes, produtos, transações e demais atividades financeiras.
Análise de dados	Processo de examinar e interpretar dados para identificar informações, padrões e possíveis relações.
Privacidade	Proteção das informações relacionadas às pessoas e ao uso adequado de seus dados.
Transparência	Clareza sobre informações, processos e critérios utilizados em determinada atividade ou modelo.
